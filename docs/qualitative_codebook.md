# Codebook de análisis para Constitutional AI

Versión inicial de trabajo para entrevistas comunitarias.

## 1. Propósito del codebook

Este codebook sirve para analizar entrevistas comunitarias y convertir hallazgos en insumos trazables para la redacción de una Constitutional AI con sensibilidad cultural.

Su objetivo es reducir interpretaciones apresuradas, mantener consistencia entre analistas y distinguir claramente entre evidencia textual, inferencia y vacíos de información.

## 2. Reglas generales de codificación

- Codificar primero lo explícito; inferir solo cuando el contexto lo permita razonablemente.
- No romantizar, simplificar ni universalizar la experiencia narrada.
- Separar lo que la persona hace, lo que considera correcto y lo que cree que debería hacerse.
- Si un fragmento mezcla experiencia personal y afirmación comunitaria, registrar ambos niveles por separado en observaciones.
- Marcar todo tema sensible, restringido, sagrado o sujeto a permiso para revisión humana posterior.

## 3. Escala de confianza

- **Alta:** el hallazgo aparece de forma directa, clara y repetida o muy bien formulada en la entrevista.
- **Media:** el hallazgo es plausible y está apoyado por evidencia parcial, pero requiere contraste adicional.
- **Baja:** el hallazgo depende de un fragmento ambiguo, de audio deficiente o de una inferencia débil.

## 4. Procedimiento ante ambigüedad

- Si el audio o la transcripción son confusos, registrar el problema en observaciones y no derivar principios fuertes.
- Si no queda claro el alcance de una afirmación, preguntar o marcar como pendiente de validación.
- Si dos fragmentos parecen contradecirse, conservar ambos y anotar la tensión en vez de resolverla artificialmente.

## 5. Flujo recomendado de trabajo

1. Transcribir o revisar la transcripción base.
2. Segmentar en fragmentos con evidencia útil.
3. Aplicar códigos primarios y secundarios.
4. Asignar nivel de confianza y observaciones.
5. Extraer patrones recurrentes y tensiones.
6. Redactar principios preliminares con advertencias.
7. Enviar a revisión humana y, cuando corresponda, validación comunitaria.

## 6. Tabla central de categorías de análisis

| Código | Definición operacional | Cuándo usar | Cuándo no usar / cuidado | Ejemplo orientativo |
|---|---|---|---|---|
| Valor | Orientación ética o criterio de lo deseable expresado o claramente sugerido por la persona entrevistada. | Cuando el fragmento diga o implique que algo es bueno, correcto, importante o preferible. | No usar si el fragmento solo describe una acción sin juicio normativo. | Honestidad, ayuda mutua, respeto. |
| Norma | Regla práctica o social sobre lo que se debe o no se debe hacer. | Cuando aparezcan expresiones de obligación, costumbre obligante, permiso o prohibición. | No confundir con valor general; la norma apunta a conducta esperada. | No entrar a terreno ajeno; avisar antes de acusar. |
| Práctica | Acción recurrente, procedimiento o forma de hacer las cosas en la vida cotidiana. | Cuando se describa cómo se trabaja, decide, cultiva, comparte o resuelve algo. | No elevar automáticamente una práctica a valor o principio moral. | Repartir costos, limpiar parcela, consultar al grupo. |
| Límite | Frontera de acceso, uso, conocimiento o comportamiento aceptable. | Cuando el fragmento marque restricción, reserva, permiso necesario o abstención. | Distinguir entre límite territorial, social, ritual, lingüístico o epistémico. | No cualquiera entra; ciertos temas requieren permiso. |
| Autoridad | Persona, grupo o criterio reconocido para orientar decisión, validar información o resolver conflictos. | Cuando se mencione quién decide, quién sabe o a quién se consulta. | No asumir autoridad formal si solo aparece coordinación práctica. | Asamblea, mayores, grupo de socios, especialista local. |
| Excepción | Caso en el que una regla, práctica o límite no aplica de forma ordinaria. | Cuando el entrevistado diga que algo cambia según situación, persona o contexto. | No inventar excepciones si no están indicadas en la evidencia. | Se puede entrar si hubo aviso o permiso previo. |
| Bienestar o vida buena | Ideas sobre vivir bien, cubrir necesidades, equilibrio, tranquilidad o suficiencia. | Cuando se hable de alimentación, tranquilidad, suficiencia, trabajo digno o bienestar compartido. | No reducir bienestar a ingreso monetario si la evidencia no lo hace. | Sembrar para comer primero; vivir con calma. |
| Reciprocidad o comunidad | Relaciones de apoyo mutuo, cooperación, responsabilidad compartida o interdependencia. | Cuando se destaque ayudar, colaborar, decidir con otros o sostener obligaciones recíprocas. | No romantizar como armonía total ni borrar conflictos. | Me ayudo, te ayudo; hacemos como grupo. |
| Territorio o naturaleza | Referencias a tierra, parcela, monte, agua, cultivo o relación con el entorno. | Cuando el sentido del fragmento dependa del espacio físico o del uso territorial. | Distinguir propiedad, acceso, cuidado, uso y simbolismo si la evidencia lo permite. | Respeto al terreno ajeno; trabajo de la parcela. |
| Justicia o conflicto | Formas de manejar problemas, acusaciones, daños, reparación o sanción. | Cuando se describa cómo reaccionar ante conflicto o cómo resolverlo. | No asumir sistemas jurídicos completos a partir de un caso puntual. | Preguntar primero; avisar antes de escalar. |
| Lengua o significado | Términos locales, traducciones difíciles o conceptos cuyo sentido depende del contexto cultural. | Cuando una palabra requiera explicación adicional o no tenga equivalencia simple. | Registrar dudas semánticas en observaciones. | Ejido, socios, apartarrayo, conceptos locales. |
| Sensibilidad o restricción | Contenido que podría requerir permiso, resguardo o validación especial antes de reutilizarse. | Cuando el tema parezca íntimo, ritual, sagrado, políticamente delicado o culturalmente restringido. | Si hay duda, marcar para revisión humana. | Saberes reservados, ubicaciones delicadas, prácticas sujetas a autorización. |
| Insumo para IA | Fragmento que puede traducirse en criterio de comportamiento, evaluación o abstención para un modelo. | Cuando la evidencia permita derivar una regla operativa para prompting o evaluación. | El insumo debe conservar límites, contexto y nivel de validación. | Pedir contexto; no generalizar; abstenerse si falta permiso. |
| Vacío de información | Ausencia relevante de datos que limita la interpretación o la redacción de principios. | Cuando falte comunidad, rol, lengua, autoridad, contraste o claridad suficiente. | No llenar vacíos con imaginación; convertirlos en acción sugerida. | No se conoce cargo del participante; falta validación colectiva. |

## 7. Formato sugerido para registro de codificación

- ID de entrevista.
- Marca de tiempo o número de fragmento.
- Cita textual o paráfrasis controlada.
- Código primario.
- Código secundario, si aplica.
- Interpretación breve.
- Nivel de confianza.
- Sensibilidad o permiso requerido.
- Observaciones y necesidad de validación.

## 8. Cierre

Este documento debe considerarse un instrumento vivo. Puede ajustarse conforme aparezcan nuevas entrevistas, categorías emergentes o criterios acordados con la comunidad y el equipo de investigación.
